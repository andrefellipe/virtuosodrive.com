> R-01 Reviewer note: Mostly fixed: one worst-case row size (about 1,300 bytes) and a typical one (about 200) are now stated, NFR9.24 is limited to the typical sample, the 6 MB limit is named, and the 4,000-item worst case is tested on the server. Two gaps remain. First, 4,000 worst rows is about 5.2 MB, which is over the 5 MB refusal point in NFR11.21, so the test in that same requirement (4,000 worst-case items must be sent) would trip the requirement's own refusal. Second, no page test shows how the 4,000-row answer behaves against the page's 10-second try limit (BR3.7), only that 4,000 rows are shown. Lowered from Major because the figures now hang together within a few percent.
